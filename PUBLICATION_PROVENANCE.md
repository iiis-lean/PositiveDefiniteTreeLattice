# Publication provenance

This repository publishes migrated final LC truth. Its historical immutable release Git ref was not retained; no historical `lc-export.json` is fabricated.

`publication-files.json` records SHA-256 checksums of the actual published files, plus changes relative to the immutable export where available. README, attribution and publication documentation can therefore evolve without rewriting mathematical release identity. The manifest excludes itself and records submodules separately.

All locally available Source Corpus material from the publication baseline is included. Author originals, curated transcriptions and maintainer notes retain the distinctions recorded in the corpus guide. Third-party material retains its authorship and original terms; the repository code license does not relicense it.
